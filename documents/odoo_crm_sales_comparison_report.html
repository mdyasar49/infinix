📌 1. Executive Summary

This master technical document consolidates all visual UI element inspections, database security models, permission matrices, and system configuration audits comparing Administrator (admin - Superuser / System Admin) against CC Admin (ccadmin - Application User / Custom Admin) within the CC_Live_Stage database on the Canadian Crystalline Odoo ERP instance (https://app.canadiancrystalline.info).

Both user sessions were audited across the core CRM and Sales business suites, side navigation bars, header action menus, smart stat buttons, list/kanban/form architectures, and system debranding parameters. The inspection was performed purely via automated, read-only Python RPC and Odoo 19 Web Session APIs without modifying any screen layout, data record, or system configuration.

🚨 Key Audit Takeaways:

  1. Security Group Discrepancy (21 Missing Groups on ccadmin): While both users are flagged with role = group_system, Administrator holds 47 security groups, whereas ccadmin holds only 26 security groups. ccadmin is restricted to Sales / User: All Documents and lacks Sales / Administrator (Group 19), Dashboard / Admin (Group 49), and administrator groups for Inventory, Purchase, Manufacturing, and Accounting.
  2. Appsbar Navigation Collapse (9 Apps vs. 3 Apps): Administrator accesses 9 full business applications on the side appsbar. ccadmin sees only 3 applications (CRM, Sales, Settings), with 6 complete business modules hidden.
  3. CRM & Sales Submenu Depletion: In CRM, ccadmin has 17 submenus compared to admin's 32 submenus (missing HOD Dashboard, Teams, Approval Settings, and the entire 14-item Configuration menu). In Sales, ccadmin has 9 submenus compared to admin's 31 submenus (missing Sales Teams, entire 4-item Reporting suite, and entire 18-item Configuration suite).
  4. Revocation of Record Deletion Rights: delete="False" is enforced on both List and Form views for ccadmin in both CRM Leads and Sales Quotations. ccadmin cannot delete any leads or quotations.
  5. Sale Order Smart Stat Buttons Stripped: Administrator sees 6 smart stat buttons on the Quotation/Order header (Projects & Tasks, Delivery Shipments, POS Orders, Purchase Orders, Manufacturing Orders, and Unlock). For ccadmin, all 6 stat buttons are completely hidden.
  6. Debranding Leaks (Odoo & OdooBot): Partner ID 2 (OdooBot, odoobot@example.com) is injected into the web client session on every page load; 8 Discuss channels feature OdooBot in their titles; 12 email templates contain unbranded "Odoo" text; runtime support_url remains https://www.odoo.com/buy; and email_secondary_color remains default Odoo purple (#875A7B).
